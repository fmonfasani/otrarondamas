# Wapsell — Conflict Resolution
**Status:** PROPOSED

Contradictions are recorded before resolution.

Each conflict must contain:
- Conflict ID
- Topic
- Sources
- Exact disagreement
- Evidence
- Impact
- Status
- Required decision

The agent must not silently choose between contradictory sources.

> **R3 note (2026-09-30) — additive; this document remains `PROPOSED` and was not approved by this note.** ISS-08 (Owner ruling, R2) fixes the precedence used to weigh sources: Owner Ruling > Decision Register > canonical SPEC > TO-BE > Audit (evidence only) > Workshop/preparation > historical (Decision Register §8.4). It does not remove the rule above: a contradiction that needs a new Owner decision is documented as `OWNER APPROVAL REQUIRED`. Formal approval of the `00-GOVERNANCE` documents remains `OWNER APPROVAL REQUIRED`.
