# Wapsell — Documentation Protocol
**Status:** PROPOSED

## Sequence
1. Inventory sources
2. Classify sources
3. Reconstruct AS-IS
4. Detect conflicts
5. Register decisions
6. Build Canonical SPEC
7. Build Transformation
8. Build TO-BE
9. Build traceability
10. Organize annexes
11. Review and approve

The agent must preserve terminology, expose uncertainty and stop at decisions that materially affect scope, business behavior, architecture or contracts.
