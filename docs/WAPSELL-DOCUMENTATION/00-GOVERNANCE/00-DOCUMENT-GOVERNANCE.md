# Wapsell — Document Governance
**Status:** PROPOSED | **Version:** 0.1

## Purpose
Define governance rules for transforming source documentation and evidence into controlled Wapsell specifications.

## Hierarchy
1. Requirements
2. General Specification
3. Specialized Specifications
4. Architecture
5. Contracts
6. Invariants
7. Tests / Evals
8. Plan
9. Tasks
10. Implementation
11. Validation
12. Review
13. Delivery

## Principles
- Do not assume.
- Do not invent.
- Do not silently reconcile contradictions.
- Preserve source material.
- Separate AS-IS from TO-BE.
- Distinguish documented proposals from approved decisions.
- Maintain traceability.
- Do not claim implementation without evidence.

## Evidence classifications
- VERIFIED BY CODE
- VERIFIED BY TEST
- VERIFIED BY EXECUTION
- DOCUMENTED
- NOT DETERMINABLE
