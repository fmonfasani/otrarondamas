AGREGAR LOGIN A OTRA RONDA MAS
════════════════════════════════════════════════════════════════════════

PASO 1: Crear carpeta de login
────────────────────────────────
mkdir -p apps\pos-admin\src\features\login

PASO 2: Copiar archivos
─────────────────────────
1. LoginPage-updated.tsx → apps/pos-admin/src/features/login/LoginPage.tsx
2. App-final.tsx → apps/pos-admin/src/App.tsx (REEMPLAZAR)

PASO 3: Instalar y verificar
────────────────────────────
cd apps/pos-admin
npm install
npm run build
npm run dev

PASO 4: Probar
────────────────
1. Abre http://localhost:5173/
2. Verás el login con:
   - IZQUIERDA: Logo OTRA RONDA MAS + fondo negro
   - DERECHA: Formulario de login + fondo gris
3. Usa cualquier email/contraseña (es demo)
4. Entra al dashboard

PASO 5: Logout (opcional)
─────────────────────────
Para agregar logout, actualiza Sidebar.tsx:
- El botón "Salir" limpia localStorage y redirige a /login

════════════════════════════════════════════════════════════════════════

ARCHIVOS NUEVOS:
- LoginPage.tsx → formulario de login con diseño lado a lado
- App.tsx → rutas actualizadas con protección

CAMBIOS:
- Login page = fondo negro + logo a la izquierda, gris + formulario a la derecha
- Dashboard/POS solo accesibles si estás logueado
- localStorage guarda el estado de login
