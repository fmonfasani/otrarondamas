# Otra Roonda Más — MVP piloto

Aplicación web SaaS para gestionar la operación comercial de Otra Roonda Más (ventas, pedidos, pagos, caja, clientes, inventario, compras, entregas, reportes y auditoría).

Desplegada como aplicación independiente bajo `otrarondamas.wapsell.com`, con infraestructura compartida con Wapsell pero sin dependencias de código ni datos entre ambos (ver [docs/SDD-especificacion-funcional-v0.1.md](docs/SDD-especificacion-funcional-v0.1.md), sección 7).

## Estado

Borrador funcional v0.1 — pendiente de validación del dueño. Sin stack técnico definido todavía (fase de diseño, ver sección 11 del SDD).
