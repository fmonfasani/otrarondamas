 WHAT THIS PIPELINE DOES
================================================================================

On every push to the main branch:

1. Code Quality Checks
   - ESLint validation
   - TypeScript type checking
   - Fails if errors found

2. Build Application
   - npm ci (clean install)
   - npm run build
   - Generates production bundle

3. Optional Tests
   - Jest test execution
   - Can be skipped in emergencies

4. Security Scan
   - npm audit vulnerability check
   - Non-blocking (advisory only)

5. Deploy to Hetzner VPS
   - SSH to 89.167.96.239
   - Backs up current build
   - Deploys new build
   - Installs dependencies
   - Runs database migrations
   - Restarts application (PM2)

6. Health Checks
   - Verifies SSH connectivity
   - Checks process is running
   - Validates API responds
   - Confirms database connection
   - Monitors system resources

7. Comprehensive Verification
   - System status
   - Application logs
   - Build information
   - Database status
   - API endpoint tests
   - Environment validation
   - Security checks

8. Slack Notifications
   - Success/failure messages (optional)
   - Detailed error reporting

Expected Duration: 20-30 minutes per deployment

================================================================================
 QUICK START (5 Steps)
================================================================================

1. Generate SSH Key
   ssh-keygen -t ed25519 -C "github-actions-deploy" \
     -f ~/.ssh/github_deploy_key -N ""

2. Add SSH Key to Hetzner
   ssh root@89.167.96.239
   echo "$(cat ~/.ssh/github_deploy_key.pub)" >> ~/.ssh/authorized_keys

3. Configure GitHub Secrets
   Go to: Settings → Secrets and variables → Actions
   Add 4 secrets:
   - HETZNER_HOST: 89.167.96.239
   - HETZNER_USER: root
   - HETZNER_SSH_KEY: (paste private key)
   - HETZNER_SSH_PORT: 22

4. Prepare Hetzner VPS
   mkdir -p /var/www/wapsell
   npm install -g pm2
   Create .env file with:
   - DATABASE_URL
   - JWT_SECRET
   - NODE_ENV=production

5. Test Deployment
   Push to main branch or manually trigger workflow

================================================================================
 TROUBLESHOOTING
================================================================================

SSH Connection Failed:
  - Verify HETZNER_SSH_KEY secret is correct
  - Check SSH key is added to Hetzner
  - Test: ssh -i ~/.ssh/deploy_key root@89.167.96.239

Build Failed:
  - Run locally: npm run lint --workspace=@otrarondamas/api
  - Run locally: npx tsc --noEmit
  - Run locally: npm run build --workspace=@otrarondamas/api

Health Check Failed:
  - SSH to Hetzner: ssh root@89.167.96.239
  - Check logs: pm2 logs wapsell
  - Check migrations: npx prisma migrate status
  - Restart: pm2 restart wapsell

See: .github/workflows/SETUP_GUIDE.md#troubleshooting for detailed help

================================================================================
 ROLLBACK PROCEDURE
================================================================================

Automatic:
  - If health check fails, automatic rollback occurs
  - Previous build restored from .backups/ directory
  - Application restarted automatically

Manual:
  bash scripts/rollback-deployment.sh 89.167.96.239 root ~/.ssh/deploy_key 22 1

Where:
  89.167.96.239 = Hetzner VPS IP
  root = SSH user
  ~/.ssh/deploy_key = SSH private key
  22 = SSH port
  1 = backup number (1=latest, 2=second latest, etc.)
